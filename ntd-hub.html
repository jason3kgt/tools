PM Contracts
Paste rows with 4 columns, in this order: Facility Name, Frequency, Start Date, Notes. Frequency can be written loosely (quarterly/monthly/semi-annual/annual, or just "Q"/"4x/yr" etc.) — it gets normalized automatically. Start Date can be YYYY-MM-DD or MM/DD/YYYY; for a facility with no contract start on file yet, its last known PM visit date works as a stand-in so due-date tracking can start immediately. A name that exactly matches an existing facility updates it (without touching anything else on file); a new name creates a facility. Notes are optional and land in that facility's PM Contract "Scope" field — skip a facility's Notes column if it already has real scope text you don't want overwritten.
