Customer Import

Bulk-load customer/facility records into NTD Hub — safe to reuse for future exports

1. Data to import

Pre-loaded with your Foundation customer list export (376 rows). Format is one customer per line, tab-separated: Name [tab] Address [tab] City, State [tab] Notes. To reuse this tool later with a fresh export, just replace the contents of this box (copy/paste straight from Excel keeps the tabs intact) and hit Preview again.

2. Review before publishing

Nothing has been written to Supabase yet. New rows will create a facility. Already in Hub rows matched an existing facility by name (your 17 PM facilities will show up here) — checking their box only fills in address/city fields that are currently blank, it never overwrites anything you've already entered. Needs review rows had a similar-but-not-exact name match — each gets a dropdown instead of a checkbox: default is Skip (does nothing), or you can pick "Same site as ___" to safely fill gaps on that existing facility, or "Different site — create new" if it genuinely isn't the same place.
